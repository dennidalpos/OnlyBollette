# OnlyBollette

Windows x64 desktop application for Italian household offers. UI copy is Italian; code and documentation are English. Do not replace real source retrieval with demo offers.

- Runtime truth is in `src-tauri/src`; React talks only through Tauri IPC. Web-only preview must report unavailable native capabilities explicitly.
- Market-free energy XML and PLACET CSV are discovered from the current Portale Offerte page; do not construct date-based URLs. Retain source URL, retrieval timestamp, validity and exact price components.
- An index spread is not an energy price. Missing prices are not zero. `src/electricity.ts` estimates only supported fixed domestic PLACET electricity, with current official parameters. Never label this subset a whole-market ranking; other energy estimates use the official portal. Insurance requires a personal quote.
- AI uses only source text with `evidenceVersion=1`, excluding app annotations; legacy evidence requires refresh. Summary keys include the provenance version. No model-generated prices or external AI API. Runtime archives and GGUF revision/hash are pinned.
- Runtime binaries are generated by `npm run prepare:runtime` and ignored by git. Do not commit model weights, runtime archives, caches or test evidence. Data lives under the user's app-local directory.
- On this machine Rust is installed under `$env:USERPROFILE\.cargo\bin` without persistent PATH modification.
- `ONLYBOLLETTE_DATA_DIR` must be absolute and redirects database/models. Native checks use isolated scratch data; `ONLYBOLLETTE_TEST_MODEL` supplies a read-only AI test original. Vite must ignore `.scratch` and `test-results`: locked WebView2 files crash its watcher.

Verified commands: `npm run build`, `npm test`, `npx playwright test`, `npm run package`, `pwsh -NoProfile -File scripts/build-installer.ps1`, `npm audit`, `cargo test --manifest-path src-tauri/Cargo.toml --lib`, `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`, `pwsh -NoProfile -File scripts/verify-source-values.ps1`. Native verification may hit intermittent Allianz HTTP 403. Open work is in `PROJECT_STATUS.json`; live example effects are in README.md.

Live checks fail on any failed/partial source or missing calculation parameters; do not bypass access challenges. Failed-refresh warnings are session-only; partial web catalogs replace snapshots and retain their warning. AI checks may download 1.4 GB into dedicated test data.
